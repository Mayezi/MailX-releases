# v0.89.0 (2026-11-20)

## 新功能

- **收件人 / 抄送 / 密送顶部 Tab 详情视图**：点击摘要行中的「等 N 人」、「抄送 N 人」、「密送 N 人」或「展开详情」，在原地切换为「收件人 / 抄送 / 密送」顶部下划线 Tab 切换栏，支持展示分组人数、一键复制分组全部地址及内联显示 `回复至` 地址。
- **底部「更多」菜单集成「查看源码」双区弹窗**：将「查看源码」入口收纳至阅读器底部「更多」抽屉内（默认收起），弹窗分为上下两区展示完整「邮件消息头」（含项数统计与一键复制）及「邮件源码」（自动识别并标注 `原始 MIME 源码` 或 `RFC 5322 源码`），底部支持一键导出 `.eml`。

## 改进

- **信头视觉层级与 14px 信息排版**：将精确收发时间与标签行移至主题下方并统一采用 `14px` 字号，保留浅底描边圆角标签徽章样式；发件人行与收件摘要行去除了顶部多余标签与地址截断，收件人 / 抄送人保持单行实时宽度自适应且完整展示 `姓名<邮箱地址>`。
- **正文上方默认展开 3 列无边框附件卡片**：附件区默认保持展开状态并位于信头下方、正文上方，采用 3 列轻量浅底无边框卡片网格展示文件图标、扩展名与大小，支持复制文件名、应用内预览弹窗及批量下载；在预览弹窗内点击「系统打开」时校验附件安全风险后再调用系统默认程序。

## 问题修复

- **修复阅读器地址折行错乱并兼容置顶操作**：修复邮箱地址芯片内部姓名与 `<邮箱>` 折行拆裂导致右侧展开入口被挤压偏移的问题，同时完整保留底部「更多」菜单中的本地邮件置顶 / 取消置顶功能。
