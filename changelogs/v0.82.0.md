# v0.82.0 (2026-11-18)

## 新功能

- **三端本机身份验证查看密码**：查看已保存的邮箱密码或授权码时，Windows 优先弹出仅需 PIN / 指纹 / 人脸的系统安全中心窗口（未启用 PIN 时自动回退至仅验证当前用户的系统密码校验），macOS 接入 Touch ID / 开机密码验证，Linux 接入 Polkit 系统授权弹窗。
- **单步原子校验与防窥保护**：后端将身份核验与凭据读取合并为单步操作，验证通过后明文开启 20 秒自动隐藏倒计时，并提供一键「复制授权码」按钮。

## 改进

- **账号密码区域回显体验**：已保存密码的账号在编辑弹窗中默认展示掩码占位与「已保存」状态徽标，支持直接输入新密码覆盖或按需验证后查看，不再显示为空白。
- **验证弹窗线程隔离**：将三端系统身份验证逻辑置于独立工作线程阻塞等待，避免验证期间阻塞主窗口渲染。

## 问题修复

- **修复 CI 安装包归档路径异常**：修复 Cargo Workspace 模式下 `main` 分支工作流扫描不到 `target/release/bundle` 安装包产物导致上传失败的问题。
