# v0.91.2 (2026-11-22)

## 改进

- **阅读页收件人文案与人数排版优化**：将阅读页信头的「收件人」调整为更自然的「发给」，实现「发给 / 抄送 / 密送」两字工整对齐并收紧少人直出左列宽度；多人模式下将人数顺移至头像堆叠右侧，按是否折叠智能展示「等 X 人」（超过 3 人）或「X 人」（3 人及以内与密送），阅读动线与中文语感更顺滑。
- **点击已选分组支持一键收起**：展开收件人详情抽屉后，除点击其他分组丝滑切换外，再次点击当前已选中的「发给 / 抄送 / 密送」胶囊可直接收起详情区域。
- **收件人展开栏视觉精简**：移除展开工具栏右侧的「全部 / 内部 / 外部」筛选按钮以及抽屉底部的计数说明条，保留快速查找与一键复制，信头展开区域更清爽聚焦。
