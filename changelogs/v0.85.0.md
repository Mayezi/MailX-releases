# v0.85.0 (2026-11-19)

## 新功能

- **版本历史与更新中心**：新增独立「版本历史与更新」窗口，聚合展示各版本更新日志、当前版本标识及各平台安装包下载入口；桌面端支持在应用内一键更新与重启生效。
- **自动更新后台下载**：启动软件或驻留运行检测到新版本后，桌面端会在后台自动静默下载并校验安装包，完成后弹出轻量提醒支持一键「重启更新」；手动点击更新后也可切至后台继续下载。
- **自动检查更新开关**：「设置 → 常规设置 → 启动与关闭」新增「自动检查更新」开关，支持按需控制启动及后台检测行为。

## 改进

- **设置页与更新弹窗视觉统一**：统一设置页左右分栏与更新弹窗面板底色层级，精简「关于 MailX」页版本与运行状态展示，并将「打开软件时自动收取新邮件」开关统一对齐到右侧。
- **设置文案精简优化**：全面梳理并精简设置页各分组选项标题与说明，去除重复配置项与冗余表述，使整体更直观易懂。
