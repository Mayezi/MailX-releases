# v0.93.1 (2026-11-24)

## 性能优化

- **列表切换秒开**：新增消息列表首屏缓存（stale-while-revalidate），切回已访问过的文件夹时先用上一轮结果立即铺满列表，再在后台静默重查校正，点击不再出现空白等待。
- **空闲预取「已发送」**：应用空闲且未选中会话时，自动预取已发送首屏并写入缓存，首次点开已发送也走缓存秒开。
- **重复查询合并**：一次切文件夹原本会因多轮状态更新触发多次相同查询，现改为 55ms 合并 + 同参数请求复用同一 Promise，实测一次点击从 5 次重复查询降为 1 次。
- **列表响应瘦身**：Rust 与 Web 两端的列表查询改为轻量投影，列表不再返回 `body_html` / `body_text`（正文改由阅读面板按需加载），大幅减小 IPC / HTTP 响应体积与 JSON 解析开销。

实测（12,001 封已发送、生产构建）：切换首屏约 120–140ms，单次列表查询 8–15ms。
