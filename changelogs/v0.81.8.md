# v0.81.8 (2026-11-18)

## 改进

- **解耦发信与收信**：移除邮件发送完成 2 秒后自动触发全量收信的定时器，发信仅归档至「已发送」，不再触发非预期同步。
- **精简附件预览弹窗**：移除顶栏及画布中的上一/下一切换、原邮件、打开所在文件夹与转发等冗余按钮及快捷键提示，保留「系统打开 / 另存为 / 关闭」。
- **账号添加与收取设置优化**：
  - 统一 `IMAP`、`POP3`、`Exchange` 的「在服务器上保留邮件副本」与「服务器保留时长」策略配置并同步传递至后端；
  - 将「测试连接」按钮紧凑置于「邮箱与密码」标题行右侧，移除重复的全局同步时间范围与通用授权码提示；
  - 将 `POP3 / SMTP` 卡片描述规范为「单向收取并本地归档」，并统一「首次同步范围」与「服务器保留时长」下拉框向上展开。
- **搜索联想交互**：补全发件人/收件人筛选下的角色相关性联想建议，并移除搜索范围默认勾选「全部」的状态。

## 问题修复

- **修复桌面端托盘编译问题**：修复 `update_tray_unread_state` 移动 `app` 导致的 Rust 借用冲突（`E0505`）。
