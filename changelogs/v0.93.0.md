# v0.93.0 (2026-11-24)

## 新功能

- **邮件列表 Foxmail 式折叠分组**：列表按「排序」自动生成可折叠分组标题行，分组名后标注「（N 封）」，点击标题行即可收起/展开，默认展开。
  - 按日期排序：置顶邮件 / 今天 / 昨天 / 本周 / 上周 / 两周前 / 三周前 / 上个月 / 更早（以周一为一周起点，上个月按自然月划分）。
  - 按发件人排序：置顶邮件 / A–Z 首字母（中文按拼音首字母归并，无法判定的归入「其他」）。
  - 按大小排序：置顶邮件 / 超过 10 MB / 1–10 MB / 100 KB–1 MB / 小于 100 KB / 未知。
- **宽表与窄卡片两种列表形态同步支持分组**，虚拟滚动按「分组标题行 / 邮件行」分别估算行高，折叠状态按排序方式独立记忆，来回切换排序不会串台。

## 修复

- **「上个月」分组边界**：改为按自然月取上一个完整日历月，修复了今天落在月初时上月邮件被误并入「更早」的问题。
