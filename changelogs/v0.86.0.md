# v0.86.0 (2026-11-19)

## 新功能

- **版本详情一键下载安装包**：在「版本历史与更新」右侧详情顶部新增「下载」按钮，点击即可直接下载对应版本的 Windows 安装包，无需跳转网页手动查找。
- **左下角头像快捷编辑个人资料**：左下角账号头像右下角新增编辑图标，点击可直接打开「发件人与签名」配置当前邮箱的发件人名称、标识色与邮件签名。

## 改进

- **版本历史列表与精确时间展示**：标签图标移至左侧版本列表逐条展示，移除右侧版本号外框与标题底部分隔线，顶部图标、发布时间与按钮严格水平对齐；发布时间支持精确到分秒展示，同日多次发布一目了然。
- **关于 MailX 页面体验与文案升级**：将「已是最新版本」及更新检测状态移至首行版本号后同行显示；移除 Logo 与功能图标背景底框并放大尺寸；全面重塑功能特色文案，突出 AI 接入、极速本地检索与隐私保护。
- **欢迎页信息精简**：移除状态胶囊上方重复的邮件数量统计文字，保留温馨问候语与状态卡片。
- **Gmail 风格邮件翻页控件**：阅读邮件右上角的上一封/下一封切换改为左右方向圆形图标按钮与紧凑计数（如 `1 / 25`），去除多余按钮文字。

## 问题修复

- **跨仓库自动发布流水线修复**：为 GitHub Actions 发布步骤补充 `releaseCommitish: main`，解决将 Windows 安装包发布至公开更新仓库时因目标提交引用无效导致创建 Release 失败的问题。
- **头像编辑角标视觉修复**：去掉左下角账号头像编辑按钮外层多余的轮廓线条，改为单层圆润描边与轻量阴影展示。
