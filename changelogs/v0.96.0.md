## 新功能

- **通讯录自动发现本机客户端并一键导入**：通讯录导入新增「自动查找本机客户端」默认入口，自动以只读方式扫描本机已安装的 **Foxmail**、**Thunderbird** 与 **网易邮箱大师** 通讯录数据库。
  - 扫描结果显示各客户端发现的通讯录来源与联系人数量，支持单客户端「一键导入」、多客户端「一键导入全部」，导入时自动按邮箱智能去重合并并同步创建对应分组。
  - 支持先点击「预览」筛选目标联系人或调整归属分组后再导入；检测到加密数据库时会清晰提示并引导导出 `.vcf` / `.csv` 文件。
  - 若客户端数据存放在自定义位置，可直接点击「指定目录扫描」定位数据文件夹进行扫描。
- **发信前附件提醒升级为官方内置插件**：原内置的发信前附件遗漏提醒升级为默认启用的官方内置插件，在独立沙箱中运行。
  - 可在顶栏独立入口「插件中心」中随时一键启停，自由配置同时检测主题、忽略引用原文与签名、自动排除否定表达、仅在未添加附件时提醒及自定义追加触发关键词。
  - 支持一键「复制为本地插件」，方便在此基础上自行扩展专属发信检查规则。
- **插件中心独立为一级功能入口**：将插件管理从「设置」中独立拆分为专属「插件中心」工作台，顶栏右上角新增插件图标直达；原「主题与外观」工作台完整融合至「设置 → 主题与外观」，顶栏更清爽聚焦。
- **「写邮件」入口直接选择模板新建**：左侧栏顶部「写邮件」升级为分割式按钮，点击右侧下拉箭头可直接按模板创建新邮件，支持变量实时预览与手动填空弹窗。

## 改进

- **明暗主题切换升级为圆形双向扩散动效**：基于浏览器原生 View Transitions API 实现从点击坐标向视口边缘扩散的 800ms Standard Ease 双向圆形切换动画，并搭配太阳 / 月亮平滑变形图标与零闪烁快照机制。
- **模板选择浮层动线与视觉精简**：左侧列表精简为单行模板名称，去除冗余标签干扰；「管理模板库」移至浮层右上方，「用此模板写邮件」置于右下角并统一底部操作栏，同时移除写信编辑区底部重复的「模板」入口。
- **插件管理工作台体验完善与开关统一**：统一插件列表、工具栏「开发者热重载」及「插件配置」布尔选项的开关样式；新增内置插件防误删保护、源码只读查看、一键「恢复默认配置」、代码保存前校验与搜索空状态提示。
- **应用更新下载提示更清晰**：更新弹窗与更新中心明确区分桌面端「应用内后台自动下载」与回退时的「打开浏览器下载」，避免对下载方式产生误解。
