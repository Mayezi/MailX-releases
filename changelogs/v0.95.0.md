# v0.95.0 (2026-11-25)

## 新功能

- **导入「挪移模式」：导入一封、删一封**：导入向导新增可勾选的挪移开关，默认关闭。开启后每封邮件成功入库即从源里移除：Maildir（每封一个 `.eml`）按批落库后逐封删除，单封成本 O(1)，不影响导入速度与内存；mbox 整夹一个文件无法单封删除，改为流式读取、整夹全部成功后一次性删除源文件，任何一封失败就整夹保留，绝不出现“删了却没入库”。浏览器上传的文件是临时副本，不支持挪移，界面已写明。
- **模板库补齐增删改查**：模板面板支持搜索、编辑（名称 / 分类 / 收件人 / 抄送 / 密送 / 主题 / 正文）、复制副本、删除二次确认，列表标注「含变量」与变量数量。
- **模板变量体系（38 个 / 5 组）**：新增 `{{recipientName}}`、`{{firstName}}`、`{{company}}`、`{{senderName}}`、`{{signature}}`、`{{date}}`、`{{dateLong}}`、`{{year}}`、`{{month}}`、`{{monthName}}`、`{{day}}`、`{{weekday}}`、`{{week}}`、`{{weekOfYear}}`、`{{quarter}}`、`{{time}}`、`{{datetime}}`、`{{timezone}}`、`{{subject}}`、`{{threadSubject}}`、`{{cursor}}`、`{{random}}` 等；支持 `{{变量|兜底文案}}`，变量名大小写不敏感，未识别变量原样保留。套用与预览都按“当前时间 + 当前收件人”实时渲染。
- **附件预览扩展到 PPTX 与文本类文件**：`.pptx / .pptm / .potx` 逐页抽取文字预览（不做像素级还原，避免排版引擎与字体风险）；`.txt / .log / .md / .json / .xml / .yml / .csv / .tsv / .sql / .bat / .sh / .ini` 等按纯文本预览，CSV/TSV 自动转成表格，GBK/GB18030 老文本自动识别编码。全部本地解析，不联网、不执行脚本、不调用系统 Office。

## 改进

- **导入进度更可信**：逐封删除在实时日志里按“已移除 N/M”回报，导入结束汇总新增“已从源删除 X 封、释放 Y”的统计；删除动作统一写入导入诊断日志。
- **挪移删除全程做安全校验**：只允许删除本次扫描出的邮件目录内的文件，拒绝删除 MailX 数据目录内的任何路径，原生端与服务端各自独立校验。

## 问题修复

- **修复老版 Office 提示文案**：`.doc / .ppt / .pot / .pps` 明确提示“另存为 .docx / .pptx 后即可应用内预览”，不再笼统提示不支持。
