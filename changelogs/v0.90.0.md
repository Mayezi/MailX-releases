# v0.90.0 (2026-11-20)

## 新功能

- **阅读器信头「轻盈头像堆叠」与原地展开抽屉**：重构邮件阅读器收发信头为常驻卡片布局，收起与展开共用同一操作行，点击「收件人 / 抄送 / 密送」或「展开」时在原地平滑展开联系人胶囊列表；左侧持续保留头像堆叠样式并优先突出当前账号（「我」），右侧原地呈现成员快速查找、「全部 / 内部 / 外部」独立筛选胶囊及「复制」操作。
- **附件收起态多附件层叠折叠展示**：附件栏默认以紧凑条展示前 2 个附件（保留复制文件名、预览与下载快捷按钮），超出 2 个时在右侧以层叠卡片形式呈现隐藏附件的文件类型图标与 `+N` 计数，点击即可展开全部 3 列附件卡片并查看单个文件类型与大小。
- **邮件正文全量自动识别外部链接**：除已有超链接外，现已在 HTML 正文与纯文本正文中统一自动识别 `http://`、`https://`、`www.` 及常见裸域名链接，自动剥离末尾多余中英文标点与不配对括号，同时避开邮箱地址、常见文件扩展名及代码块，点击后统一走外链安全确认流程。

## 改进

- **附件操作栏与视觉分隔精简**：附件区顶部标题行始终显示附件总数与总大小，将「展开 / 收起」与「全部下载」统一左对齐靠拢排布（悬浮背景仅作用于操作按钮本身），并移除附件区顶部多余边框、弱化发件人与收件人之间的分割线透明度。
- **精简普通外链跳转确认弹窗**：点击普通安全链接时不再展示冗余说明文案，标题图标调整为轻量主题色外链图标，仅在展示文本与目标链接存在差异时显示「邮件内显示文字」，同时完整保留可疑与高危钓鱼链接的风险警示与二次确认。
- **文案与主题一致性优化**：将信头分组与展开按钮文案统一规范为「收件人 / 抄送 / 密送」及「展开 / 收起」，激活筛选胶囊统一采用主题主操作色，兼容全部明暗主题配色。

## 问题修复

- **修复发件人姓名、邮箱与职务对齐及字体不一致问题**：将发件人改用纯文本行内渲染并统一 `15px` 字号与 `items-baseline` 基线对齐，修复邮箱地址与职务在垂直方向上轻微偏移以及悬浮变色被内联样式覆盖的问题。
- **修复收件人分组切换时的短暂布局抖动**：为分组与筛选胶囊保持固定边框并改为颜色过渡，切换分组时自动复位列表滚动位置，消除切换瞬间的卡顿与位移。
