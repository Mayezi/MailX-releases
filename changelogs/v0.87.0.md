# v0.87.0 (2026-11-19)

## 新功能

- **收件人与抄送人单行宽度自适应**：阅读器顶部信头摘要支持根据当前窗口与分栏宽度实时测算，自动控制在单行展示并动态调节可见人数与抄送折叠入口，避免多人邮件占满首屏。
- **多人收件信息组内筛选与一键复制**：百人级收件人、抄送与密送展开后，支持在顶部实时关键词筛选，并可按分组一键复制全部成员邮箱地址。

## 改进

- **现代无边框信头详情样式**：重构「展开详情」面板，移除冗余背景底色与单人边框，统一采用清爽分隔线、标准 `姓名<邮箱地址>` 排布与 `;` 分隔符，并为可展开入口统一添加主题引导色。
- **姓名与邮箱地址字体体验统一**：全局默认字体切换为系统原生无衬线字体，统一阅读器、写信联想与悬停名片中姓名与邮箱地址的字号与字重，避免中英文混排大小不一或使用特殊装饰字体。
- **写信页多收件人滚动保护**：当回复全部或群发收件人超过 16 人时自动限制输入区最大高度并支持内部滚动，防止主题与正文编辑区被挤出首屏。
- **阅读器顶部双栏附件卡片与统一预览**：将阅读器附件区域从底部工具栏移至信头下方、正文上方，采用支持折叠沉浸阅读的双栏卡片网格与文件类型图标徽章，保留复制文件名、全部下载与另存为按钮，并将点击与预览统一接入应用内预览弹窗（与附件管理保持一致，不再直接调用系统原生程序）。

## 问题修复

- **跨仓库自动发布 Tag 同步修复**：在 GitHub Actions 同步更新日志至公开更新仓库时预先创建并推送对应版本 Tag，解决跨仓库创建 Release 时因目标引用或 Tag 未就绪导致的 `tag_name` / `target_commitish` 校验失败。
