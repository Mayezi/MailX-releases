# v0.84.0 (2026-11-19)

## 新功能

- **版本检测与更新提示**：启动后静默检查是否存在新版本，有更新时以轻量通知提示新版本号与更新内容，提供「查看更新」入口跳转 Release 页面；可关闭并在静默期内不再打扰，不打断邮件收发。
- **设置页手动检查更新**：「设置 → 关于 MailX」新增版本检测卡片，显示当前版本，支持手动检查更新；检测到新版本时展示更新说明与「前往下载」入口，已是最新或检查失败均有明确状态提示。

## 改进

- 更新检测优先读取 GitHub 最新 Release 信息，缺失时回退更新器清单与版本更新日志；无网络或无权限时静默跳过，不影响正常使用。
