# v0.88.0 (2026-11-20)

## 新功能

- **邮件置顶**：邮件列表与阅读器支持置顶 / 取消置顶，置顶邮件始终排在列表最前（组内仍按当前排序规则排列）；置顶为纯本地标记，不同步到 IMAP/POP3 服务器，重启后保留。
- **标签徽章醒目化**：邮件列表与阅读器中的自定义标签由纯彩色文字改为带浅色底色与描边的圆角徽章，标签色同时用于图标、文字、底色与边框，辨识度更高。

## 问题修复

- **修复版本检测误判「已是最新」**：远程更新源可达但未取到任何版本记录时，不再把本地内嵌或缓存的旧版本误当成线上最新；清单仅声明 `latestVersion` 缺少明细列表时，按该版本兜底解析。
