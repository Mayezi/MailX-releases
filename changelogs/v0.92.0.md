# v0.92.0 (2026-11-23)

## 新功能

- **已发送邮件「回复来源」定位条**：在「已发送」与「定时发送」中查看回复或转发邮件时，若本地存在对应原邮件，阅读器收件人栏下方自动展示单行「回复来源」定位条，清晰呈现回复/转发关系、原发件人、原邮件主题、附件数、时间与所在文件夹。
- **原邮件快速阅读与一键定位**：点击「回复来源」定位条即可直接阅读原邮件并保持当前发件箱列表位置不变，阅读器顶部同步提供「返回已发送回复 / 返回已发送转发」按钮（支持 `Esc` 快捷返回）；点击右侧「定位原邮件」可一键切换至原邮件所在文件夹与账号并自动滚动高亮定位。
- **多级原邮件精准追溯引擎**：支持按本地直连回复 ID、标准 `In-Reply-To` / `References` 邮件头、`thread_id` 会话索引及去前缀主题与时间多级精准匹配原邮件，同时完善了回复/转发写信与 `.eml`/`.mbox` 导入时的引用头留存。

## 改进

- **左中右三栏布局阅读区空间精简**：三栏布局下正常阅读邮件时不再渲染阅读器顶部的上一封/下一封切换条容器，释放更多垂直正文阅读空间（两栏布局下继续保留返回与上下封切换）。
- **收件人信息卡片视觉更纯净**：移除阅读器收件人外部卡片的渐变 `background-image`，统一使用纯色主题表面，观感更利落清爽。
