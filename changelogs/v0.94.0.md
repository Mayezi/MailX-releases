# v0.94.0 (2026-11-25)

## 新功能

- **二维码钓鱼（Quishing）拦截**：正文图片内的二维码在本地解码（不上传图片、不联网），命中后直接展示扫码落点，并按形近域名 / 短链 / 裸 IP 等规则给出风险分级，提示「请勿用手机扫码」。
- **BEC 商务邮件诈骗横幅**：付款、收款账户变更、薪资、发票等话术命中时单独拉出高可见度横幅，并给出「核对真实发件域名 / 用存档电话回拨 / 收款账户变更双人复核」三步动作。
- **会话发件人变更提示（线程劫持）**：同一主题历史发件域名固定、本封更换发件域时，在阅读器顶部提示「此前来自 / 本封来自」，并说明涉及付款与权限变更需另渠道核实。
- **形近 / 同形字域名徽标**：发件域命中形近域（0/o、1/l、rn/m 等替换）或 Punycode 混合字符时，在发件人卡上直接标注「形近仿冒域名 / 同形字域名」。
- **拒收黑名单（安全与 AI · 防钓鱼安全）**：支持精确邮箱与 `@domain` 整域黑名单，出厂内置 6 个安全运营通报地址（带「内置」标识），可逐条删除、可一键恢复出厂列表；命中黑名单的来信在导入时直接投递「垃圾邮件」并记录拦截原因。

## 改进

- **附件真实类型持续告警**：附件文件化后正文不再持有 base64，落盘时把「真实类型 / 加密压缩包」快照写入附件元数据，列表与阅读器仍能识破后缀伪装与密码压缩包。

## 改进

- **安全防护全部可开关**：新增「二维码扫码提醒 / 会话中途换人提醒 / 假域名识别 / 附件真身校验 / 谈钱邮件单独提醒」五项开关，说明全部改成日常说法；关掉即真的不生效，原有「钓鱼识别、高危锁定链接、远程图片、外部发件人、回复异常地址」五项行为保持不变。
- **附件新增 Word / Excel 应用内预览**：`.docx` 直接看正文与表格，`.xlsx / .xls` 支持多工作表切换；全部在本地解析，不联网、不调用系统 Office、不执行宏与外部链接，打开附件不再需要先落盘。
