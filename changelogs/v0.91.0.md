# v0.91.0 (2026-11-20)

## 新功能

- **独立「发现新版本」更新确认弹窗**：检测到新版本后自动弹出独立页面，集中展示当前版本与最新版本号对比、发布日期以及分级排版的更新内容，由用户主动决定是否下载，底部同步保留「查看历史版本」入口。
- **用户可控的应用内下载与重启安装**：取消所有未经确认的后台静默自动下载；点击「立即下载更新」后在弹窗内实时展示下载进度条、字节数与校验状态，支持随时点击「后台下载」关闭弹窗继续办公，下载校验完成后切换为「重启并安装」由用户手动确认重启（网页预览或无签名更新包时自动回退至浏览器下载安装包）。
- **会话级「稍后提醒」策略**：不想立刻升级时点击「稍后提醒」即可关闭弹窗，本次运行期间不再重复弹出同一版本，下次重启客户端后会再次提醒。

## 改进

- **设置页检查更新体验优化**：在「设置 → 关于」点击「检查更新」发现新版本时，不再自动触发后台下载，改为在设置页内展示更新摘要与「查看更新」按钮，点击后打开独立的「发现新版本」确认弹窗；同时更新「自动检查更新」开关说明为「启动时检测新版本并弹窗提醒，不会自动下载」。
- **启动引导阶段防弹窗遮挡**：若应用正处于首次数据目录选择或新手引导阶段，检测到新版本时会暂缓弹出更新提醒，待引导完成后再平滑展示。
