# v0.91.1 (2026-11-22)

## 改进

- **左侧导航栏丝滑展开与收起**：统一收起态宽度与各分组标题槽位高度，锁定顶部「写邮件」、收信按钮、邮件夹、工作资产、标签及底部账号头像在同一垂直中轴线上，彻底消除展开/收起时的横向与纵向跳动；同时统一收起态图标尺寸与展开态一致，并移除收起态刷新按钮的默认底色。
- **阅读页收件人栏轻重自适应展示**：当「收件人 / 抄送 / 密送」各自均不超过 3 人时，免展开直接按行展示统一风格的联系人胶囊（含姓名、邮箱地址、本人与外部域标识及整行快速复制）；任一分组超过 3 人时自动切换为头像堆叠与可展开抽屉模式。
- **多人分组切换滑动胶囊动画与布局优化**：为多人模式下的「收件人 / 抄送 / 密送」切换加入平滑滑动的主题色胶囊指示器，将分组名称与人数调整至胶囊左侧、堆叠头像顺移至右侧，与少人直出模式保持一致的阅读动线；同时精简分组标签，移除多余的「· 我」文字，通过头像堆叠首位高亮的「我」直观标识自己所属分组。
- **收件人详情抽屉丝滑展开与收起**：为多人模式下的收件人详情面板加入平滑的高度展开、透明度渐变与轻柔位移动画，同步联动右侧搜索筛选工具栏的淡入滑出与箭头旋转，快速切换或切换邮件时均保持自然过渡无闪烁。
- **阅读页发件人信息精简**：移除邮件阅读顶部发件人行的职位/岗位展示，信头视觉更清爽聚焦。

## 问题修复

- **修复联系人胶囊文字底部裁切与对齐偏移**：调整胶囊固定高度、行高与基线组合方式，修复英文下伸字母与中文底部笔画在截断时被裁切的问题，并使右侧姓名与邮箱地址与左侧圆形头像保持严格水平居中对齐。
